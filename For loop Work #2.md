### **Python Skill Check: For Loops**

#### **The Scenario**
You have a list representing the number of items sold each hour at a local bakery.

```python
hourly_sales = [12, 15, 8, 22, 14]
```

#### **Your Challenge**
Write a `for` loop that calculates the total number of items sold over these 5 hours.

#### **Instructions**
1. Create a variable named `total_sales` and set it to `0`.
2. Write a `for` loop to loop through the `hourly_sales` list.
3. Inside the loop, add each hour's sales to your `total_sales` variable.
4. Print the final total after the loop finishes.markdown
