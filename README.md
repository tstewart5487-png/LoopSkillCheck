# LoopSkillCheck

A Python repository for practicing and testing fundamental **for loop** skills in Python.

## Overview

This repository contains skill check exercises focused on mastering `for` loops in Python. The exercises cover essential loop concepts including:

- Basic list iteration
- Working with `range()`
- The accumulator pattern
- Combining loops with conditionals

## Repository Contents

### Files

- **`Loop work #4.md`** - Skill check assignment with 4 tasks to complete
- **`Loop work #4.py`** - Solution file with completed implementations of all tasks
- **`main.py`** - Sample PyCharm template file

## Exercises Overview

### Task 1: Basic List Iteration
Iterate through a list of colors and print each one on a new line.

### Task 2: Working with Ranges
Use `range()` to print numbers from 1 to 5 (inclusive).

### Task 3: The Accumulator Pattern
Calculate the sum of numbers in a list using a `for` loop and the accumulator pattern.

### Task 4: Loops and Conditionals
Loop through numbers 1-10 and identify whether each is even or odd.

## Key Concepts Demonstrated

- **For loops with lists** - Iterating through list elements
- **Range function** - Creating sequences of numbers
- **Accumulator pattern** - Building a total through loop iterations
- **Conditional logic in loops** - Using `if/else` statements within loops
- **Loop variable scope** - Understanding how loop variables work

## How to Use

1. Start with the exercises in `Loop work #4.md`
2. Write your solutions following the specified requirements
3. Compare your solutions with the completed examples in `Loop work #4.py`
4. Run the code to see the outputs
